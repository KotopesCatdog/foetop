Справка / Help

Русский

  • Для загрузки базы данных установите расширение для браузера FOEhelp по ссылке на главной странице сайта
  • В своём городе нажмите на расширение -> "Импорт JSON" и сохраните файл.
  • Затем укажите на папку с сохраненным файлом.
  • ==========
  • Кнопка "📁 Выберите папку" — выбрать папку с JSON файлами
  • Автоматически загружается самый свежий JSON файл из папки
  • При обновлении файла в папке данные обновляются автоматически
  • ==========
  • Клик на карточке здания - показ-скрытие данных
  • Удержание ЛКМ на здании добавляет его в корзину
  • Клик по колонке в корзине — сортировка
  • Колонки в корзине можно перетаскивать
  • Выбор эпохи и параметров для фильтрации
  • ==========
  • Внимание! Ведутся работы, возможны неточности

English

  • To load the database, install the FOEhelp browser extension via the link on the main page
  • In your city, click on the extension -> "Import JSON" and save the file.
  • Then point to the folder with the saved file.
  • ==========
  • Button "📁 Select folder" — choose a folder with JSON files
  • The latest JSON file from the folder is loaded automatically
  • When the file in the folder is updated, the data updates automatically
  • ==========
  • Click on a building card - show/hide data
  • Hold LMB on a building to add it to the basket
  • Click on a column in the basket — sort
  • Columns in the basket can be dragged
  • Select era and parameters for filtering
  • ==========
  • Attention! Work in progress, possible inaccuracies
