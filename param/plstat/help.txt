Граница между зданиями — это закрывающая }, и открывающая {:



json        "type": "military"    ← последнее поле здания
      }                       ← конец здания (строка 1730)
    },                        ← закрывает внешний объект (если есть вложенность)
    {                         ← начало следующего здания (строка 1731)
      "allyRoom": null,
      "boosts": [...]


Самый простой способ найти границы конкретного здания — искать его entityId или name, затем листать вверх до ближайшей открывающей { на том же уровне отступа.
